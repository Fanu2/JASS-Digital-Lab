ENGINEERING PRINCIPLES

Portable by design.

Core application logic should remain independent of a particular host, database, storage provider or payment provider whenever practical.

Cloudflare is the first deployment target, not a permanent architectural dependency.

Projects are developed incrementally, with documentation and clear boundaries between core logic and infrastructure adapters.
