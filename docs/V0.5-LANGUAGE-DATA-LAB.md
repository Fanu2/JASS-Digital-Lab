# JASS Digital Lab v0.5 — Language & Data Lab

## Purpose

v0.5 introduces the **Language & Data Lab**, a dedicated portfolio area for JASS language technology, corpus exploration, transliteration datasets and research-oriented data tooling.

## Featured areas

- Punjabi Roman–Gurmukhi transliteration
- Punjabi Aksharantar-derived research data
- Mizo–English parallel data
- Mizo corpus exploration
- Portable SQLite research databases
- Desktop-first and offline-friendly workflows

## Design principle

The Language & Data Lab presents data as a reusable software asset:

**Collect → Structure → Explore → Reuse**

The page is intentionally independent of a specific hosting provider. It is static HTML/CSS/JavaScript and can be deployed through Cloudflare, GitHub Pages, Netlify, Vercel, a VPS or another static host.

## Integration

Copy the v0.5 files into the existing JASS Digital Lab repository:

- `website/language.html`
- `docs/V0.5-LANGUAGE-DATA-LAB.md`

Then add a navigation link and optionally connect language-related product cards to `language.html`.

## Next direction

v0.6 can introduce the **Desktop Software Lab**, bringing together File Organizer Pro, SQLite Explorer, Media Inventory, Universal File Converter, Subtitle Studio and other practical desktop applications.
